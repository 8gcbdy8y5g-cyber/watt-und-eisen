# watt & eisen

Trainings-App für Lauf, Rad und Kraft als installierbare Webseite (PWA). Die Seite enthält keine Daten.
Die Daten liegen in einem eigenen, privaten Repo und werden mit einem Zugangs-Token geladen, der nur im Browser des jeweiligen Geräts gespeichert ist.

Auf dem Handy öffnen und „Zum Home-Bildschirm“ wählen.
